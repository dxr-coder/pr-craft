# AutoPR 项目 · 学习路线图

## 这个项目在做什么？

做一个 AI 系统：你给它一个需求（Issue），它自动写代码、测试、提交 PR。

## 整体路线

| 阶段 | 内容 | 核心知识点 |
|------|------|-----------|
| 第 0 阶段 | 环境准备 | Git、Python、PyCharm 配置 |
| 第 1 阶段 | Git + GitHub | 版本控制、commit、push、PR |
| 第 2 阶段 | FastAPI 基础 | API、路由、请求响应 |
| 第 3 阶段 | LLM 集成 | AI API 调用、Prompt 设计 |
| 第 4 阶段 | LangGraph 编排 | 多 Agent 协作、状态图 |
| 第 5 阶段 | GitHub API | 自动化创建 PR |
| 第 6 阶段 | 端到端串联 | Webhook、完整工作流 |
| 第 7 阶段 | 前端看板（可选） | React、WebSocket |
| 第 8 阶段 | Docker 部署（可选） | 容器化、CI/CD |

## 怎么用这些笔记

- 每节课一个 md 文件，按顺序看
- 文件里有"动手练习"的步骤，跟着做
- 有不懂的标记 ❓，直接问我
